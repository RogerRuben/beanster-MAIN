# Beanster Sips V19.4 · 分层咖啡角接入与 P1 动作

把 `art/production-v2` 素材包接到 App 首页：分层房间、独立杯子、收杯仪式按 manifest 坐标绑定手部锚点。睡眠、拍掌、擦汗、手指遮挡和冷凝水/汗滴/问号特效一并接入。收藏室货架改为每行 4 格，杯子使用独立 PNG。记录规则不变：保存立即写入 `records`，次日收杯只用上次桌面快照。

## 首页

- 首页房间换成 `art/ref` 风格的日/夜全景（书架、窗景、藤蔓、海报、黑板），桌上再叠仓鼠和杯子。
- 待机只用坐姿表情帧，不再混入挥手图集。夜间睡眠从同一坐姿视频抽帧，头会慢慢低下，爪子留在桌沿。
- 仓鼠坐在凳子上，收杯体型与待机相同。杯子从桌面飞到手上再进盒子，多杯逐杯收，桌上未收的杯子留着。
- 跨天收杯杯子只在 `cupAttached` 帧挂在手上，release 后进入盒内。结束后拍掌；收 3 杯及以上改擦汗。
- 跳过、减少动态效果、退到后台都会落到静止状态；记录不会被动画删除。
