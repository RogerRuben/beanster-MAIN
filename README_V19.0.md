# Beanster Sips V19.0 · 仓鼠咖啡角与咖啡收藏室

版本代码 49；包名 `com.beanstersips.v11`。使用原版签名，可覆盖安装。

## 功能

- 首页咖啡角采用像素场景、透明桌面和新饮品图集。仓鼠直接复用原有 PNG / 逐帧动画，咖啡角不使用汉堡造型；非汉堡角色仍可通过表情册选择。
- 桌面只显示按本地日期筛选的今天记录，最多四杯，超过四杯提供今日收藏入口。每只杯子按记录 ID 打开详情。
- 咖啡因、杯数、热量、花费、连续天数、记录按钮保留。四种可定制仪表盘在首页展开区中可继续使用。
- 底部新增收藏室入口。原照片页从收藏室右上角进入，系统返回可回首页。
- 收藏室读取同一份 `records`，不复制、搬运、按品种合并或删除数据。保存后记录立即可在收藏室中查询；补记只进入对应日期的收藏架。
- 按日期分组，支持名称、品牌、日期搜索；每次显示 60 条，可继续加载，保证完整记录可访问。
- 单杯详情提供完整名称、品牌、年月日与时间、容量、咖啡因、热量、价格、评分、备注、照片及编辑/删除；照片沿用原图查看和保存机制。
- 新增、编辑、删除、撤销、导入后的相关页面读取同一份记录刷新；日期修改会改变桌面归属。

## 收杯规则

`settings.coffeeDesk` 只保存上次可见桌面的日期与记录 ID。跨天首次进入首页时，只为这些已变成历史日期的记录生成视觉副本。开始前先保存今天的状态，所以跳过、强制退出或连续多日未打开都不会重复收杯。

动画约 1.8 秒，可跳过；启用系统减少动态效果时直接完成。今天的新杯子独立保留，补记的旧记录从未进入桌面快照，因此不会误加入动画。动画不修改任何记录数据。场景动画通过原有 `Motion` 控制器与头像、表情和仪表盘互斥。
