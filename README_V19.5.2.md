# Beanster Sips V19.5.2 · 收藏室即时打开，咖啡角有自己的呼吸

版本名 `19.5.2`，versionCode `56`。

## 收藏室

从仪表盘或咖啡角打开收藏室时，先在隐藏页里画好标题、货架和杯子，并预载货架与杯子图片，下一帧再切到收藏室。启动后的空闲时间也会预热一次。页面切换时不再先露出一块白屏。

## 咖啡角的两套节奏

仓鼠和咖啡各有一个倒计时，播完再随机下一次，不用同一个间隔。

- 白天仓鼠 7–15 秒：眨眼、看向一侧、看杯子、微笑、轻歪头。
- 夜间仓鼠 12–24 秒：慢眨眼、犯困、低头、轻轻 Zzz。
- 咖啡 14–30 秒：热饮冒气，冷饮凝水，偶尔闪光。
- 最近两次动作不会马上重复。
- 点仓鼠从更活泼的一组里播一次，播的时候再点会忽略。
- 点杯子先给这杯一个冷热反应，再打开这杯的记录。
- 点画面空白处不再让整张画布都触发同一个动作。
- 收杯开始时两边都停下，结束后重新计时。

每个首页仓鼠片段都以 `hamster_idle_base` 开始和结束。画布 512×512，pivot 与桌沿接触点都是 (256, 448)，根节点位置和缩放不变。

仪表盘旁的小仓鼠仍只在进入、状态变化和点击时动一次。

## 仪表盘

底部留出导航栏和安全区，最后一个按钮可以完整停在导航上方。页内大标题改成今天的状态，页签上的「今日仪表盘」保留。左右滑动的文字提示只出现一次，之后变成 `● ○`。

## 启动器图标

`resources.arsc` 以前是压缩存放的，系统读不到图标资源，安装后就落到默认图标。现在这张表按未压缩、4 字节对齐写入，应用和启动 Activity 都指向 `res/drawable/icon.png`。
